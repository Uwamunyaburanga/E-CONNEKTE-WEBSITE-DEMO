E-CONNEKTE front-end prototype
Open index.html in a browser.

Files:
- index.html: page structure
- styles.css: responsive blue design
- script.js: interactive demo behaviour

Interactions included:
- Mobile navigation
- Carpool ride search and offer/request ride dialogs
- Marketplace category filters and save buttons
- Sell item and contact seller dialogs
- Accommodation, arrival checklist and local connection dialogs
- Join profile demo

Important: this is a front-end prototype. It does not store data, authenticate users, publish real rides or listings, send messages, or process payments. A live product needs a backend/database, secure accounts, moderation, privacy controls and legal/insurance review. In this browser prototype, the correct language is JavaScript (not Java); Java is a separate language.

Latest refinements
- Compact distinctive E-CONNEKTE header and clearer navigation.
- Homepage explains the platform in one short message; additional "Who we are" copy is hidden until requested.
- Carpooling cost-sharing estimator uses distance, consumption, fuel price, tolls and passenger count. It divides estimated trip costs across driver + passengers. It is an indicative calculator, not a fare recommendation or legal determination.
- Sample rides and the arrival checklist are progressively disclosed to keep the page uncluttered.
- Ride request and offer dialogs are front-end demonstrations only; a live platform needs backend matching, a private messaging/consent flow and verified user accounts.
